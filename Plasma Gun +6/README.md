# Plasma Gun +6 (Chemira)
- Plasma Gun is a futuristic assault rifle fed with 45 rounds of plasma shells. Although the projectiles move slower than bullets, the damage is massive. It uses the powerful energy of plasma and destroys everything in sight.

## Screenshots :
![de_dust20004](https://i.ibb.co/QjYJxfTN/Plasma-Gun6.jpg)

## Instructions && Installation :
- Compile plug-in with **AMX Mod X v1.10.0.5467** or newer.
- Copy and paste first INI settings in `ze_extra_items.ini` and second in `zombie_escape.ini`.

## INI Settings :
```ini
[Plasma Gun]
NAME = Plasma Gun
COST = 30
LIMIT = 0
LEVEL = 0
GLOBAL_LIMIT = 0
VIEW_MODEL = models/CSO/v_plasmagun_6.mdl
WEAPON_MODEL = models/CSO/p_plasmagun_6.mdl
WORLD_MODEL = models/CSO/w_plasmagun_6.mdl
KB_SLOWDOWN = 0.40
```
