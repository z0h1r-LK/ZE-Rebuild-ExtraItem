# Balrog-I
- Balrog-I is an explosive bullet pistol one shot for each release, fired with high explosive bullets.

## Screenshots :
![de_dust20004](https://i.ibb.co/C5y0dhTF/de-dust20001.jpg)

## Instructions && Installation :
- Compile plug-in with **AMX Mod X v1.10.0.5467** or newer.
- Copy settings and paste them in `ze_extra_items.ini`.

## INI Settings :
```ini
[Balrog-I]
NAME = Balrog-I
COST = 15
LIMIT = 0
LEVEL = 0
GLOBAL_LIMIT = 0
VIEW_MODEL = models/CSO/v_balrog1.mdl
WEAPON_MODEL = models/CSO/p_balrog1.mdl
WORLD_MODEL = models/CSO/w_balrog1.mdl
```

##  For Weapon Menu :
- If you want disable **Balrog-I** in Extra Item, U will find `#define EXTRA_ITEM 1`, 1 = Enabled | 0 = Disabled.
- `"s" "Balrog-I" "weapon_deagle" "50" "112762925" "0"`
