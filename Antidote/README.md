# Antidote
- This an item cures Zombies and turn them to a human again.

# Screenshots :
![a1](https://i.ibb.co/1YqMVRhs/a1.jpg)
![a2](https://i.ibb.co/2BvdVTZ/a2.jpg)

# Instructions && Installation :
- Compile plug-in with **AMX Mod X 1.10.0.5467** or newer.
- Copy translation keys and paste them in `zombie_escape.txt` in section `[en]`.
- Copy console variables and paste them in `zombie_escape.cfg`.
- Copy INI settings and paste them in `ze_extra_items.ini`.

# Console Variables :
```c
// --- --- ---
// Extra Item: Antidote
// --- --- ---
ze_extra_antidote 1        // Show an antidote on the Extra Items (1 = Enabled | 0 = Disabled).
```

# Translation Keys :
```ini
MSG_ANTIDOTE_CURED = "!y[!gAntidote!y] !tYou have been cured and are now Human!y!"
MSG_ANTIDOTE_NOT = "!y[!gAntidote!y] !tConversion failed!y!"
```

# INI Settings :
```
[Antidote]
NAME = Antidote
COST = 15
LIMIT = 0
LEVEL = 0
GLOBAL_LIMIT = 3
```
